# UstazERA

## Запуск

В терминале из папки проекта:

```sh
python server.py
```

В Windows можно дважды нажать `start.cmd`.
Браузер откроется автоматически: http://127.0.0.1:8766/.
Оставьте терминал открытым. Для остановки нажмите Ctrl+C.
Вход демонстрационный: любое непустое имя и пароль.

Другой порт:

```sh
python server.py --port 8767
```

Доступ с других устройств в одной локальной сети:

```sh
python server.py --host 0.0.0.0
```

На другом устройстве откройте `http://IP_КОМПЬЮТЕРА:8766/`.
Сервер запускают на одном компьютере; остальные открывают его адрес в браузере.
Если Windows запрашивает доступ к частной сети, разрешите его для этой локальной сети.

## Файлы

- `server.py`: HTTP-сервер и запросы к MunitoAI.
- `static/index.html`: страница приложения.
- `static/styles.css`: оформление.
- `static/app.js`: логика интерфейса.
- `start.cmd`: запуск в Windows.

Ключ закреплён в `server.py` в `API_KEY`, модель в `MODEL`:
`zai-org/glm-5.3-flash`. Браузер не хранит ключ.
Проверок Host, Origin, служебных заголовков и предварительных запросов
для проверки ключа при входе нет. API вызывается только по действию пользователя.
Разбор JSON и обработка ошибок сети оставлены, чтобы сервер мог сообщить об ошибке.
Учётные записи демо-входа не ограничивают доступ к серверу.
Ключ находится в исходниках открытым текстом; не публикуйте проект.
